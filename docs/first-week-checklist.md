# 第一周执行清单（纯萌新版）

> 目标只有一个：独立完成一次“改代码 → 编译 → 烧录 → 实机验证 → Git 提交”。

## Day 0：先别碰这些

第一周暂时不要做：

- FOC
- BLDC
- PCB
- CNC
- LRA
- 耳放
- 完整 MP3 系统

这些不是现在的问题。

## Day 1：把开发环境跑起来

- [ ] 安装/确认 VS Code
- [ ] 安装/确认 Git
- [ ] 安装 SiFli-SDK-CodeKit
- [ ] 准备 SiFli SDK v2.5.1
- [ ] 确认板型 `sf32lb52-lchspi-ulp`
- [ ] 找到老师的 `course_starter` 或指定示例工程
- [ ] 第一次编译成功

记录：

```text
SDK 版本：
CodeKit 版本：
Board：sf32lb52-lchspi-ulp
编译命令/方式：
第一次编译结果：
遇到的问题：
```

## Day 2：第一次烧录

- [ ] USB 连接黄山派
- [ ] 系统能识别设备/串口
- [ ] 烧录示例固件
- [ ] 打开串口监视器
- [ ] 保存启动日志
- [ ] 确认屏幕/按键等基础行为和示例预期一致

不要只记录“成功了”，至少写清楚“我看到什么，因此认为成功”。

## Day 3：人生第一次修改

选一个很小的可观察变化，例如：

```text
Hello World
```

改成：

```text
HapticPod
```

然后：

- [ ] 修改源码
- [ ] `git diff` 看修改
- [ ] 重新编译
- [ ] 重新烧录
- [ ] 开发板显示修改后的内容
- [ ] 在开发日志记录验证结果
- [ ] Git 提交

推荐提交信息：

```text
feat(ui): customize startup text for HapticPod
```

## Day 4：学 GPIO / 按键

目标：

> 按一下实体按键 → 程序发生一个肉眼可见的变化。

例如：

- 修改屏幕文字；
- 改变一个状态；
- 输出一条串口日志。

完成后单独提交。

## Day 5：认识 RT-Thread

只需要先搞懂：

- 线程是什么；
- `delay/sleep` 是什么；
- 为什么耗时任务不能直接把 UI 卡死；
- 为什么多个任务共享数据需要规则。

暂时不需要系统学习整个 RTOS。

## Day 6：认识 LVGL

目标：做一个最小 GUI：

```text
HapticPod

> Music
  Settings
  About
```

只需要会：

- Label
- 基本布局
- 简单列表/选择
- 基础事件

## Day 7：做一个“假 HapticPod”

先不用电机。

用按键模拟：

```text
KEY1 -> NEXT
KEY2 -> ENTER
```

再在代码里尽量转换成统一输入事件：

```text
INPUT_CW
INPUT_CCW
INPUT_PRESS
INPUT_BACK
```

以后换成真实旋钮时，UI 层不需要知道输入来自电机还是按键。
